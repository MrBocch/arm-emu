# What is arm-emu? 

arm-emu is a:

  - assembler
  - virtual machine

for a toy arm32 architecture.

I am not aiming for 1 to 1 parity with a real arm computer.
This project is just for fun.

## Inspiration

This all started when I wanted to learn assembly and found this
[https://peterhigginson.co.uk/ARMlite/doc.php](ARMlite).

> ARMlite simulates a simple computer built around a cut-down version of a
> 32-bit ARM processor.

ARMlite is a webapp, with a code editor, view into registers/memory status flags
input and output and a screen.

I plan for any valid armlite program to be about the same for arm-emu.
